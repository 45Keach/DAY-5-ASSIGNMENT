This repository contains the completed Day 5 technical writing exercises.

## Contents

## Exercise A

The procedure documents how to create and activate a Python virtual environment and install a package. It is written for a first-semester computing student and includes prerequisites, one-action steps with expected results, a screenshot description, and troubleshooting.

## Exercise B

The API reference documents a hypothetical authenticated endpoint for creating a project-management task, including request parameters, headers, response codes, JSON examples, and validation behavior.
